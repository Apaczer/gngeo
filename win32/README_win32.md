Place your ROMsets and BIOS in one folder and drag and drop zipped file to BAT script:

Use `gngeo.bat`
- to run ROMset or GNO directly otherwise launch GnGeo menu directly 

Use `dump.bat` 
- to dump cached GNO file of loaded zip file in file's folder.

Default p1control bindings:
A=z,
B=x,
C=a,
D=s,
START=1,
COIN=3,
UP/DOWN/LEFT/RIGHT=ArrowKeys,
MENU=esc
